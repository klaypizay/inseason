# Practice run screen and sign-in refinement

The practice page will use the existing authenticated weekly-plan data in a three-pane coaching workspace: ordered activities and timing on the left, the selected activity's instructions in the center, and an at-a-glance coaching board on the right. Table, condensed, and detailed layouts remain available for alternate viewing and printing. No new images, inferred player performance, or external data are introduced.

New AI drafts may include a bounded run of show for each activity. The model is instructed to divide the full block duration into concrete demonstration, repetition, progression, reset, and reflection segments. These remain recommendations and are rendered as escaped text. Existing output schemas, ownership checks, quotas, immutable versions, resource limits, and exact overall-practice duration validation remain authoritative.

Routine sign-in will no longer ask an established account holder to repeat the adult-coach attestation. Account creation continues to require it, and the existing `adult_attested_at` account record remains the source of truth. Authentication still uses Supabase password or Google OAuth only for identity verification, immediately revokes the provider session, and issues the same bounded, server-revocable application session. Login rate limits, generic errors, fixed callback validation, tenant isolation, and logout revocation are unchanged.

Threat model: removing a redundant login form field does not create an account or change authorization, and an unauthenticated user still cannot reach coach data. A minor could attempt to use an already-created adult account, but the checkbox did not prevent credential sharing; provider authentication and session controls remain the relevant boundary. Model text and coach briefs remain untrusted and cannot call tools. Oversized output is bounded by existing schemas and model timeouts. Residual risks are credential sharing and the instructional quality of AI output, both requiring product policy and coach review rather than a per-login checkbox.
